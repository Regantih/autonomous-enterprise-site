The answer

The management problem, answered

Frameworks help engineers build agents. Leaders solve the management problem by owning five decisions that no framework makes.

  1. 1 Where agents act

    Which decisions should an agent make, and which belong to a rule, a model or a person?

    Start from an outcome Finance can measure, then use the simplest engine that works: rules, models or solvers before agents.

    Book, Ch 21.3 Which step goes where

  2. 2 How far they’re trusted

    How much may this agent do alone, and what evidence moves it up or down?

    Set a level per step, L0 to L5. Promotion is earned on evidence and decided by a named body; demotion is automatic.

    Book, Ch 01.5 Who sets the level

  3. 3 Who answers

    Who is accountable when this agent acts, and who may change its limits?

    Every agent has a named business owner who signs its limits and promotions and can stop it. No registry, no run.

    Book, Ch 24.3 Agents are owned, not managed

  4. 4 How you stop them

    What stops this agent, how fast, and who may pull the switch?

    The harness enforces limits and budgets. Irreversible steps stay behind human gates, and a tested kill switch stops one agent or the fleet.

    Book, Ch 05.8 The kill switch

  5. 5 Whether it pays

    Does this agent create more value than it costs, after review, incidents and fixed cost?

    Compare agents in cost per completed outcome, track each agent’s net contribution, and run pilots that end in a decision.

    Book, Ch 25.4 Cost per outcome

Frameworks build the agents; leaders own these five decisions. That is human-led, agent-operated. Book, Ch 01.1
